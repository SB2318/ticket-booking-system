# ticket-booking-system

## Requirements

- App will be listing current movies and shows
- App allows users to search for movies
- App will be listing different shows for movie
- App allows register user to book a ticket or show
- App allows add or edit theater information

## First Assumptions:

- Every theater has a single screen
- Fixed Number of seats
- Only Register users can book tickets, Guest and Authenticated users can search movies
- Register users have their history of bookings
- Movies can be multilingual
